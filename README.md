# Где я живу

PWA для iPad: показывает ребёнку, у кого он живёт сегодня и в ближайшие 7 дней. Расписание берётся из отдельного Google-календаря, который могут править оба родителя.

Как это устроено:

- Google-календарь «Где живёт сын» с событиями на весь день «Мама» и «Папа». Календарь приватный, второй родитель получает доступ на редактирование.
- Google Apps Script ([apps-script/Code.gs](apps-script/Code.gs)) читает календарь от имени владельца и отдаёт события в JSON по секретной ссылке.
- Статичное приложение (этот репозиторий) лежит на GitHub Pages, раз в 30 минут забирает JSON и хранит последнюю копию на iPad, поэтому без интернета показывает последнее известное расписание.

## 1. Календарь

1. В Google Calendar: «Другие календари» → «+» → «Создать календарь», например «Где живёт сын».
2. В настройках календаря → «Открыть доступ пользователям» → добавить маму с правом «Внесение изменений в мероприятия».
3. Там же скопировать «Идентификатор календаря» (вида `abc123@group.calendar.google.com`).

## 2. Apps Script

1. Открыть https://script.google.com → «Новый проект», назвать «Где я живу».
2. Вставить содержимое `apps-script/Code.gs`, в `CALENDAR_ID` подставить идентификатор из шага 1.
3. «Настройки проекта» → часовой пояс как у календаря.
4. Заполнить календарь: выбрать функцию `seedSchedule` → «Выполнить», разрешить доступ к календарю. Создаётся 94 события: октябрь 2026 – январь 2027 по согласованной таблице, дальше стандартный 2-2-5-5 до 31.08.2027 (`SEED_UNTIL`). Если календарь уже заполнен вручную, этот шаг пропусти.
5. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение»:
   - «Запуск от имени»: я;
   - «У кого есть доступ»: все.
6. Скопировать ссылку, которая заканчивается на `/exec`. Открыть её в браузере: должен прийти JSON со списком событий.

Ссылку знает только тот, кому вы её дали. По ней видны названия и даты событий этого календаря на 60 дней вперёд, больше ничего.

После правки `Code.gs` нужно «Управление развёртываниями» → карандаш → «Новая версия», иначе ссылка продолжит отдавать старый код.

## 3. Хостинг на GitHub Pages

```bash
git init && git add . && git commit -m "Initial version"
gh repo create where-i-live --public --source . --push
gh api -X POST repos/{owner}/where-i-live/pages -f "source[branch]=main" -f "source[path]=/"
```

Через минуту приложение откроется по адресу `https://<логин>.github.io/where-i-live/`. Ссылки на Apps Script в репозитории нет, она вводится на самом iPad.

## 4. Установка на iPad

1. Открыть адрес приложения в Safari → «Поделиться» → «На экран «Домой»».
2. Запустить приложение с домашнего экрана и вставить ссылку `/exec` (удобно переслать её себе в Сообщениях и скопировать).

Вставлять ссылку нужно именно в установленном приложении: у приложения с домашнего экрана своё хранилище, отдельное от Safari.

Настройки потом открываются долгим нажатием (2 секунды) на строку «Обновлено …» внизу экрана.

## Как менять расписание

- Поменяться днями: растянуть или сократить событие в Google Calendar, либо переименовать «Мама» ↔ «Папа».
- Разовое исключение: создать поверх короткое событие на весь день «Папа» или «Мама». Если на день попало несколько событий, приложение берёт самое короткое, при равной длине последнее изменённое.
- Событие в календаре означает, у кого ребёнок ночует. В день смены утром он ещё у прежнего родителя, а в будни новый забирает его после школы в 17:30 (`PICKUP_TIME` в `app.js`). До этого времени главный экран показывает «После школы тебя заберёт папа, в 17:30», после переключается на «Сегодня ты у папы».
- Другое время забора можно вписать в название события: «Папа 12:00». На выходных без времени приложение пишет просто «едешь к папе».
- Учитываются только события, в названии которых есть «мам» или «пап». Остальные (кружки, врач) игнорируются, но лучше держать их в другом календаре.
- iPad увидит изменения при следующем открытии приложения или в течение 30 минут.

## Разработка

```bash
python3 -m http.server 8080
```

В настройках есть кнопка «Демо без календаря»: стандартный график 2-2-5-5 без обращения к Google.

После изменения файлов приложения увеличь `VERSION` в `sw.js`, иначе iPad будет показывать закэшированную версию. Иконки пересобираются командой `node tools/make-icons.js`.
